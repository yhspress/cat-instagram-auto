이 저장소는 “인스타 고양이 대환장극” GitHub-only 자동화 저장소다.

수정할 때 다음 구조를 유지해 줘.
- data/cat_concepts_500.txt의 500개 콘셉트를 직접 읽어 활용
- Python이 각 스토리에 장소·상황·소품·반전·표정·몸짓을 하나씩 사전 배정하고 모델은 배정된 정확한 6개 ID만 사용
- 스토리 큐 리필은 정확히 5개
- 각 스토리는 원인·절정 행동·강한 표정·결정적 몸짓·결과/반전 단서를 한 프레임에 담은 HERO 이미지 1장
- 각 이미지 prompt는 영어로 독립 실행 가능하게 작성하고 고정 글자 수 제한 없이 필수 정보를 모두 포함하며, 고정 치즈태비 전체 외형 반복
- 최종 이미지 4:5(1024×1280)
- Instagram 게시물 하나는 HERO 이미지 1장 단일 이미지 게시물
- Cloudinary 등 외부 이미지 호스팅 금지
- 생성 이미지는 public/posts에 두고 GitHub에 먼저 commit/push한 뒤 raw.githubusercontent.com 공개 URL로 Instagram에 전달
- 게시 성공 후에만 queue에서 해당 story를 제거하고 creative_history/published를 갱신
- 실패 시 state/prepared.json을 재사용해 이미지 재생성 방지
- GitHub Secrets에는 AUTOPOST_ENV 하나를 사용

변경 후 python scripts/check_template.py와 Python 문법 검사를 실행해 줘.
